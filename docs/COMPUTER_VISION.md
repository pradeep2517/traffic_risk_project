# Computer Vision Integration (YOLOv8)

## Overview
We utilize Ultralytics YOLOv8 to process video streams from traffic cameras and vehicle dashcams.

## Core Capabilities
1. **Vehicle Density Estimation:** Counts cars, buses, and two-wheelers in real time to feed live congestion metrics into the risk calculation engine.
2. **Infrastructure Auditing:** Identifies road anomalies and obstacles to update pothole and hazard scores automatically.
